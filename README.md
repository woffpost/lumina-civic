# Lumina Civic — Non-Profit / NGO Landing Page

An impact-driven landing page for a civic non-profit organisation. Designed to inspire trust, communicate mission, and convert visitors to donors and volunteers.

## Features

- **Donation CTA** — amount selector with custom input → thank you confirmation
- **Programme cards** — 6 initiative cards with progress indicators and goals
- **Impact statistics** — animated counters (beneficiaries, volunteers, countries)
- **Team profiles** — leadership section with roles and backgrounds
- **Partner logos** — institutional supporters grid
- **Volunteer sign-up** — name, email, skills → confirmation
- **Mobile navigation** — responsive hamburger menu

## Tech Stack

- [Next.js 16](https://nextjs.org/) — App Router
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) — icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
